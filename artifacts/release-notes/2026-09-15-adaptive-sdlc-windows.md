# AI SDLC — адаптивный процесс и установка на Windows

**Release notes · 15 сентября 2026**

Два обновления сокращают лишнюю работу при доставке изменений и упрощают установку AI SDLC Loop.

## 1. Адаптивный SDLC

**Релизы:** [Backbone 5.6.0](https://github.com/mikegorelikoff/ai-sdlc-backbone/releases/tag/v5.6.0) · [Loop 0.9.0](https://github.com/mikegorelikoff/ai-sdlc-loop/releases/tag/v0.9.0)

Глубина процесса теперь зависит от риска и неопределённости задачи:

| Режим | Когда применяется | Процесс |
| --- | --- | --- |
| **FAST** | Небольшие понятные изменения с низким риском | Контекст → реализация → целевые проверки |
| **STANDARD** | Обычные фичи и нетривиальные исправления | Контекст → компактный план → реализация → проверки |
| **DEEP** | Архитектура, безопасность, миграции, высокая неопределённость | Полный SDLC с необходимыми специализированными проверками |

- Автоматическая классификация и повышение глубины без перезапуска задачи.
- Общий контекст и повторное использование доказательств вместо повторного чтения и анализа.
- Проверки по риску, ограниченные повторные попытки и параллельное выполнение явно независимых команд.
- Метрики этапов, проверок и эскалаций; неизвестные значения не выдаются за измеренные.

**Качество:** сохранены обязательные разрешения, контроль области изменений и полный процесс для сложных задач. Ускорение полного цикла с реальной моделью пока не измерено.

## 2. Windows-установщик Loop

**Релиз:** [Loop 0.10.0](https://github.com/mikegorelikoff/ai-sdlc-loop/releases/tag/v0.10.0), включает адаптивный SDLC из 0.9.0.

**[Скачать Windows x64 Setup (.exe)](https://github.com/mikegorelikoff/ai-sdlc-loop/releases/download/v0.10.0/ai-sdlc-loop-0.10.0-windows-x64-setup.exe)** · **[SHA-256](https://github.com/mikegorelikoff/ai-sdlc-loop/releases/download/v0.10.0/ai-sdlc-loop-0.10.0-windows-x64-setup.exe.sha256)**

Откройте файл, выберите папку проекта и **Codex** или **Claude Code**, нажмите **Install**. Мастер установит 26 skills и проверит результат.

- Автономная установка без прав администратора и предварительной установки Python.
- Сохранён CLI для автоматизации и других совместимых агентов.
- Локальные изменения защищены: установщик останавливается при конфликтах и не перезаписывает их.

**Проверено:** Windows-сборка, открытие GUI, все три профиля и работа EXE без Python в PATH; повторная установка, контроль целостности и отказ на небезопасных путях. Регрессионный CI проходит на Windows, macOS и Linux.

**Важно:** EXE пока без цифровой подписи. Встроенный Python используется только установщиком; для дальнейшего запуска skills на Python нужен поддерживаемый Python. Автоматическое обновление существующих установок не добавлено.

[Инструкция по установке на Windows](https://mikegorelikoff.github.io/ai-sdlc-loop/guides/windows-install/)

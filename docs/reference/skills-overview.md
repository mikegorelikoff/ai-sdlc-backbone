# Skills overview

This legacy path intentionally does not reproduce private skill packages. The
public workflow model is documented in [How it works](../how-it-works/index.md).

## Framework health and quality discovery

| Capability | Boundary |
| --- | --- |
| Doctor | Read-only framework structure, contracts, provenance, routing and deterministic fixture health |
| Edge-case hunter | Unusual conditions around known behavior; scenarios are not confirmed bugs |
| Blind-case hunter | Missing model dimensions after scoped source search; unknowns and exclusions remain explicit |
| Bug hunter | Concrete code evidence; confirmation requires current reproduction and contract review |

All three hunters share source-bound machine findings and skill-specific table output. They route evidence to existing delivery owners and grant no approval.

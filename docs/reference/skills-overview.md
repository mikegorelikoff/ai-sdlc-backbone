# Skills overview

AI SDLC Harness contains many focused skills, but a new user does not need to
choose among them. Start with `ai-sdlc-flow` Explore and let the route identify
the owning skill.

## Three supported entry paths

1. **Guided default:** use `ai-sdlc-flow` to Explore, review the card, then
   approve Apply.
2. **Lifecycle or role discovery:** browse
   [skills by lifecycle](skills-by-lifecycle.md) or
   [skills by role](skills-by-role.md).
3. **Direct expert invocation:** open the [searchable catalog](skills.md) and
   invoke a known owning skill with its documented flow mode.

## Selection boundary

Each skill owns a bounded outcome and hands its artifacts to a named consumer.
Do not load the complete catalog into every prompt. Read the route and exact
skill page required for the current stage.

The individual skill pages remain built and searchable but are intentionally
absent from the primary sidebar.

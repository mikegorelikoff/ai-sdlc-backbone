# Validate

## Entry

Advisory suggestions or coaching reports have been generated and structured according to the presentation profile. Output evidence is staged for integrity verification.

## Procedure

1. Verify that all suggestions cite factual event sequence numbers, session identifiers, or documented workflow transitions.
2. Confirm that all assigned confidence scores are valid floats bounded strictly between 0.0 and 1.0.
3. Verify that all recommendations are strictly advisory and opt-in, never enforcing mandatory workflow lockouts.
4. Ensure that no surveillance metrics, individual productivity scores, or external network calls are present.

## Exit

Evidence accurately reflects factual journal events, conforms to coaching guidelines, and passes all verification gates without blocking developer velocity.

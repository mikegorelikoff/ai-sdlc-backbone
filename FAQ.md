# FAQ

## What is AI SDLC Harness?

It is a licensed product for structured, traceable AI-assisted software
delivery across product, analysis, engineering, QA, and delivery roles.

## Is this the product source repository?

No. This public repository contains documentation, examples, onboarding, and
the public installer. Product implementation is distributed as an authorized
artifact.

## Do customers need private GitHub access?

No. Customers use a license key with the public installer. Only the licensing
backend authenticates to private release storage.

## How should a license key be supplied?

Use `AI_SDLC_LICENSE_KEY` through a protected environment mechanism or the
installer's masked prompt. Never pass it as a CLI argument or publish it in an
issue or log.

## Do small changes need the full workflow?

No. The installed product supports bounded quick paths and more rigorous full
flows. Use the level of rigor appropriate to risk and ambiguity.

## Where should a new user start?

Use the canonical [Start here](docs/start-here/index.md) path.
